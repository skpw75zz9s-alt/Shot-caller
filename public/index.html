            Kalshi account

            Not linked. Link it and the app reads exactly what you bought, sold and when, so there's nothing to tap.

            On Kalshi: Account → API keys → Create key. Copy the key ID and download the private key file. The key stays on this phone: it's locked in so that even this app can't read it back out, and it's never sent to our server. Linking only reads your trades and balance. Orders are placed only if you turn on Live auto-trading below, within the limits you set. Delete the key on Kalshi any time to cut access.
